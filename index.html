Web App Builder

Đọc app HTML/JS/CSS, tự phát hiện tên · phiên bản · database URL · public key, sửa an toàn và xuất ZIP.

Generic v1.0

1. Nạp source app

Hỗ trợ chọn 3 file riêng, nhiều file, cả thư mục hoặc ZIP.

Kéo thả file hoặc ZIP vào đây
Chưa nạp source.

2. Cấu hình chính

Builder chỉ thay các giá trị đã xác nhận.

3. Phát hiện tự động

Chỉ những mục bật mới được áp dụng.

Nạp source để bắt đầu quét.

4. Quy tắc thủ công

Dùng khi source viết lạ hoặc Builder chưa nhận diện đúng.

5. Adapter / Profile

Lưu mapping để lần sau mở cùng kiểu app không phải cấu hình lại.

Profile chỉ lưu cấu hình public/mapping trong trình duyệt này. Không dùng để lưu secret server.

6. Kiểm tra an toàn

Quét lỗi cấu hình và secret không nên nằm trong frontend.

Chưa kiểm tra.

7. Xuất app

Builder giữ nguyên cấu trúc file, chỉ sửa các giá trị được bật.

Thay đổi dự kiến
